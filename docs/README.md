## Как устроена документация

- Каждый документ начинается с одной строки о том, зачем он нужен.
- Длинные документы имеют «Содержание» со ссылками на разделы.
- Команды даны так, чтобы их можно было скопировать целиком.
- Непроверенное поведение помечено явно: «не проверено», «не подтверждается».

Нашли неточность или непонятное место — присылайте issue или pull request.
