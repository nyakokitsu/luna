# Калибровка LED: страница удалена, API остался

> Отдельной вкладки `/calibration` в Luna больше нет: цветом музыки управляет
> плагин в своей панели. Настройки, профили и HTTP API калибровки сохранены.

Удалена только страница интерфейса. Это не сброс LED: штатные профили моделей,
`led.calibration_gain`, логический RGB и порядок каналов, runtime API и
HTTP API панели LED продолжают работать. Существующие настройки и пресеты
остаются на месте, никакие файлы устройства не удаляются.

## HTTP-контракт

| Метод и путь | Назначение | Ограничения |
| :-- | :-- | :-- |
| `GET /api/led-panel/status` | топология ring/logo из backend, причина недоступности, defaults, владелец превью | только чтение |
| `GET`/`PUT /api/led-panel/settings` | усиление `gain_r`, `gain_g`, `gain_b` | каждое `0.05..4`, хранится как `led.calibration_gain` в настройках Luna, запись атомарная |
| `POST`/`DELETE /api/led-panel/preview` | сессия предпросмотра с продлеваемой арендой на 4 секунды | кадр содержит ровно число LED выбранной зоны в `#RRGGBB` |
| `GET`/`PUT /api/led-panel/presets` | до 16 именованных наборов усиления | 16 КиБ, отдельный файл `led-calibration-presets.json`, пути/команды/аудио не принимаются |

## Владение и ограничения

Аренда превью временно подавляет другие записи LED и `off` от Luna. Вторая
сессия не может её продлить или остановить. Превью рисует, только пока свежи
оба наблюдателя — «Алиса свободна» и «громкость известна»; если состояние
неизвестно, вывод прекращается. Речь и изменение громкости дают свой кадр.
Остановка, истечение аренды и выключение Luna возвращают штатный триггер, не
заливая индикацию пустым кадром. Потеря вкладки просто даёт аренде истечь.

Что калибровка **не** делает:

- усиление RGB действует на клиентов LED внутри Luna, но не на нативный `maind`
  и не на сторонние процессы, пишущие в LED;
- независимые записи этим механизмом не согласуются — не запускайте два
  LED-теста одновременно;
- коррекция на стороне клиента складывается с усилением Luna;
- превью применяет усиление формы один раз, штатная матрица и упаковка
  RGB/BGR не меняются.

Топология берётся из возможностей backend, а не из списка моделей в браузере.
Поддерживаются конфигурации только с логотипом и с отдельными ring/logo.
У Station 2 нативный framebuffer не квалифицирован, поэтому независимое
превью явно отключено: Luna не угадывает раскладку и владение. Для Station Max
добавлен отсутствовавший инициализатор `StationSpec.led_calibration`, чтобы все
обёртки станций собирались с текущим интерфейсом.

## Проверка

Rust-тесты покрывают валидацию усиления и пресетов, сохранение без изменения
разрешения на запуск бинарников, лимит тела, владение сессией и проверку кадров,
определение топологии, однократное применение усиления и отказ при неизвестном
состоянии наблюдателей. Страница и её браузерный mock удалены, тесты API и
backend остались.

Удаление страницы не исправляет ошибки запуска AirPlay и не меняет физическую
калибровку цвета ни на одной станции.
